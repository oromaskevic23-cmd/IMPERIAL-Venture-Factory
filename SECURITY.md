# Security Policy

## Scope
This repository currently contains portfolio specifications and local offline validation tooling. It does not currently host any of the ten production SaaS applications.

## Reporting vulnerabilities
Do **not** create public GitHub Issues for credentials, customer data, exploitable endpoints or private audit evidence. Use GitHub's private vulnerability reporting / repository owner contact if available, or an owner-approved private channel. Do not disclose secret values in screenshots or logs.

## Defensive posture
- Zero Trust / deny by default / fail closed
- AI Passport identity is not authority; Enterprise Skills are not approval
- Mandatory Guardian Core, CYBER HAK, Approval Gateway, Audit Ledger, ProofGraph at sensitive stages
- No credential retrieval, unauthorized browsing, customer-data exfiltration or active scanning
- No public disclosure of private locations, infrastructure origin detail or personal residence
- Never merge security-sensitive production releases without reviewed evidence

A vulnerability assessment claim requires documented scope, methodology and independent results.
