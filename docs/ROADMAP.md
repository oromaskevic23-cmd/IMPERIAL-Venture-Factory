# Execution Roadmap — Gated Waves

This is an ordered execution proposal, **not a calendar promise** and not evidence of completed work.

| Wave | Candidates | Why | Exit criterion |
| --- | --- | --- | --- |
| Foundation | All ten | Architecture, legal boundaries, validation plans | Reviewed specs and independent gate tests |
| 1 | ApproveDesk | Narrow client approval pain, deterministic core | One full approval E2E and real pilot evidence |
| 1b | CSVReconcile | Local-first deterministic tool | Golden test cases and buyer-reviewed result |
| 1c | InvoiceRelay | Clear accounts-receivable workflow | Authorised reminder trial and payment reconciliation |
| 2 | QuoteFlow, RenewalRadar, CatalogFix | B2B operations workflows | Individually confirmed demand and security |
| 3 | MarginLens, TicketTriage, WebhookLedger, SiteSignal | Greater correctness/cost/market risks | Pilots + independent reviews before release |

## Milestones for each candidate
1. Discovery interviews and alternative mapping.
2. ADR and Product Acceptance Contract signed.
3. Thin vertical slice: real data -> core processing -> output + export.
4. Deterministic unit/integration suite and browser E2E.
5. Security and privacy review with rollback and audit evidence.
6. Paying pilot or explicitly labeled pre-revenue transferable asset.
7. Buyer due diligence and Owner-controlled exit.

## Prioritization score (for future evidence)
`score = 0.30 * customer_pain + 0.20 * willingness_to_pay + 0.20 * build_feasibility + 0.15 * transferability + 0.15 * distribution_access`

Every factor is a **measured 0–5 rating with dated evidence**, never guessed. Until interviews and proof exist, scores remain `UNRATED`.
