# Exit Readiness — Data Room & Transfer Checklist

**Transfer only after Founder approval.** In a public repository this is a template, not proof any deal is underway.

## Ownership & IP
- [ ] Chain of title for each contributor and third-party component
- [ ] SPDX/license inventory and commercial-use permissions
- [ ] Trademarks/domain ownership and working-name clearance
- [ ] Clear carve-out for IMPERIAL Core, VELEON, CONSTRUCTOR AI, ASTRA, Guardian Core, CYBER HAK, LEGION, NCA framework, AI Passport and ProofGraph
- [ ] Assignment/license signed by the rightful owner; no unauthorized code copied into venture

## Commercial
- [ ] Reconciled payment-provider receipts, bank records and customer invoices
- [ ] MRR and churn definitions, cohorts, refunds, payment processor costs
- [ ] Concentration risk, customer contracts, authorized assignment and privacy notices
- [ ] Taxes, unpaid obligations, refunds and outstanding support incidents disclosed

## Technical
- [ ] Exact release SHA, SBOM, reproducible build and passing test bundle
- [ ] Readme, local setup, deployment instructions and secret inventory (values transferred only through secure channel)
- [ ] Independent QA report, threat model, backup + restore test
- [ ] Data export/import test, admin turnover plan and rollback notes
- [ ] Vendor quotas, spend caps, account ownership and business continuity risks

## Safety & confidentiality
- [ ] Buyer NDA where appropriate
- [ ] Redacted demo data
- [ ] Customer consent/lawful transfer basis, personal data deletion/portability rules
- [ ] No uncontrolled buyer access to source repo, production keys, crypto wallets or infrastructure
- [ ] Approval Gateway record and immutable Audit Ledger hash

## Closing
- [ ] Binding definitive agreement reviewed by qualified advisers
- [ ] Founder signature and permitted buyer credentials confirmed
- [ ] Verified settlement and reconciliation
- [ ] Transfer acceptance certificate and revocation of prior credentials
- [ ] Post-sale obligations documented; reinvestment authorized separately
